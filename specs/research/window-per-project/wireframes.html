A window per project

Wireframes for Alex, 2026-10-15. Product Owner. Nothing is built. Grey boxes are content, not design.

Decided (Alex, 2026-10-15): B and D both. They suit different people. The project window (B) is #1089. A setting, Settings ▸ Sidebar ▸ Home window, chooses All projects (default) or Launcher (D): #1090. A project window shows only its own Needs You, plus an "elsewhere" button. A notification opens in the session's project window when one is open.

First recommendation: Option B, "project windows beside the main window". The main window stays as it is. Open in New Window on a project gives a window that holds only that project. It is the same step as a popped chat (#826), one level up. It is easy to undo, because it removes nothing. Options C and D change the whole app, and they make the cross-project parts (Needs You, Activity) harder to find.
