# Tasks: Complete ACP coverage

**Input**: Design documents from `specs/003-acp-coverage/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md

**Tests**: Included. Most of this feature cannot be triggered by a runtime on this Mac (no runtime
sends an elicitation form, only one uses the file methods), so the fake agent is the only way to
exercise it. Test tasks are not optional here.

**Organization**: By user story, in the priority order the spec sets. Each story is shippable on its
own.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on unfinished work)
- Paths are exact

## Dependencies

### Phase order

- **Setup (Phase 1)**: no dependencies
- **Foundational (Phase 2)**: needs Setup. Blocks every story
- **User stories (Phases 3 to 11)**: each needs Foundational, and nothing else
- **Polish (Phase 12)**: needs the stories that are being shipped

### Between stories

Every story stands alone once Phase 2 is done. Three soft edges, which affect polish rather than
correctness:

- US3 draws a `terminal` content block from the terminal service US8 builds. Without US8 that block
  falls back to its raw form, which is what T055 is for
- US8's served writes reuse the permission question 001 built, not anything from another story here
- US7's adoption records a `session/load` replay, which reads better once US2's content blocks exist

### Inside a story

Tests, then models, then session, then daemon, then app. The one strict rule is in US8: T097 and
T101 (confinement) before T102 and T103, and T114 (the capability flags) last.

## Implementation strategy

**Ship P1 on its own first.** Phases 1 to 3 are a small change that fixes a start-losing bug, adds
boolean and grouped settings, and stops a tool call losing what it was called with. It is worth
shipping before anything else is written.

Then, in order: P2 attachments, P3 the work made visible, P4 usage. Those four cover everything a
person notices day to day.

P5 through P9 are each a self-contained afternoon or two. P8 is the largest and the only one that
can write to a disk, so it goes late and its flags go last.

foundational, 3 setup and 6 polish.
