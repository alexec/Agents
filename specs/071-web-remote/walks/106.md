# #106 walk: saying when the web remote isn't served (R3)

**Date:** 2026-10-02

**How it was run:**
- **The window:** a scratch root (`/tmp/run-r3w`) from run-app, with `launch.sh --web-port 18866` while a Python listener held `127.0.0.1:18866`.
- **Agents Host:** a second root (`/tmp/run-r3h`), set to *Run it here*. Its control plane ran as Agents Host's own launch agent, `--launch-control`, with `AGENTS_HOST_WEB_PORT=18866`. A scratch Agents Host was open on it.
- Every shot was captured by window id, behind other windows. One AX press opened Settings (by its exact title) and one pressed **Try Again**. Both were with Alex's go-ahead and the screen leased.
