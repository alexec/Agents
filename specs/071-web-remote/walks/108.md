## Left as they are

- **History (sessions the runtime holds here):** the window's button beside the runtime. The page has no session list to open.
- **Dictation:** the window only.
- **Model pill:** the window folds model, effort and fast mode into one pill. The page keeps a menu for each, and the walks choose the Model menu by name.
- **Moving a session to another worktree:** the window's place chip is a menu. The page's chip only names the place.
- **Reach on the page:** folders only, typed as full paths, because a browser can't browse the host's disk. MCP servers stay the window's, and the popover says so.
- **Sandbox chip:** not on the page before #108 and not added here.
