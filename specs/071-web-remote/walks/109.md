# #109 walk: Open in Browser

**Date:** 2026-10-02

**How it was run:**
- A run-app scratch root, `/tmp/run-obrw`, with the window, its host and its control plane. The page was served from this branch's `Web/dist` on a free loopback port (57762), never the live 8792.
- A walk's window writes the address it would open to `walks/<walk>/opened-url` in its container, and opens no browser. `Web/test/walk/openinbrowser.mjs` reads that file and opens the address in headless Chrome on a throwaway profile (`/tmp/run-obrw/chrome`), as the default browser would. A walk's window takes Chrome as the default browser's family.
- **View ▸ Open in Browser** and **Settings…** were pressed over AX, by pid and by exact title, with Alex's go-ahead. No pointer or keys were used. The Settings window was captured by window id.

## Besides the shots

- **`control.log`:** no `agents-control:2` anywhere. One `Chrome on Alex’s MacBook Air paired (browser)`.
- **Chrome's `History` database** holds the first address *with* the code. `history.replaceState` takes it out of the tab's address and Back, but not out of the browser's history store. That is why the replay above was run, and why the safety argument (security review R6) rests on the code being spent, not on it being hidden.
