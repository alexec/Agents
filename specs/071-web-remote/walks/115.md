# Walk: the page loads, and adds a project (#114, #115)

**Date:** 2026-10-02

**How it was run:**
- A run-app scratch root, `/tmp/run-w115`, with the window, its host and its control plane. Its control plane served this branch's `Web/dist`.
- A git folder, `/tmp/run-w115/work`, made empty, and no project on the host.
- The page was driven in headless Chrome 154 by `Web/test/walk/addproject.mjs`, at 1440 × 900, with a fresh browser code.
- Shots are in `walks/115/`.

## #114: the CSP line, and what stops the load

| What | Seen |
|---|---|
| The page, unpaired, on a scratch root and on the live 8792 | Loads. No CSP report, no exception, nothing in the console. |
| The page, paired, on a scratch root, at `main` | Loads into the columns. No CSP report. The column was empty, which is #115. |
| `fetch` of `/.well-known/appspecific/com.chrome.devtools.json` from the page | Chrome reports the issue's `connect-src` violation. Only that request draws it. |
| The live control plane's log as the issue was filed | `GET /`, `GET /app.js`, then `GET /.well-known/appspecific/com.chrome.devtools.json 404`. DevTools' own request reached the listener and got its 404. No browser client connected after it. |

**Finding:** the violation is DevTools' own and doesn't stop the page. The page itself never asks for that URL (the lint bans `fetch`). What can look like "doesn't load" is the page while its link is `loading` or `connecting`: it drew an empty `<main>`. It now says **Connecting…** after 0.6 s, so an ordinary connect shows nothing extra. `connect-src` is unchanged: `ws://localhost:<port>` only, pinned by `chromeDevToolsProbeIsNotFoundAndWidensNothing`.

## Differences from the window

- **Add Folder…** browses the host's folders for every host, This Mac included: the browser can't open a folder picker on the host's disk. The window does this only for servers (`RemoteFolderSheet`).
- No folder dragged in from Finder, and **Clone Git URL…** doesn't fill in a copied address: the page doesn't read the clipboard.
- **Add Server…** stays the window's (hosts have no screens on the page).

**Protocol:** `files/browse`, `projects/add`, `projects/clone`, `projects/clones` and `clone/changed` were added to `WebSignatures`. Since #111 every client may call them.
