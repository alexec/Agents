# #105 walk: the sheets that make a browser's code (071 T035)

**Date:** 2026-10-02

**How it was run:**
- **The window:** a run-app scratch root, `/tmp/run-w105`. It was run twice:
  - once with its page served;
  - once with `--web-port 18876` while a Python listener held `127.0.0.1:18876`.
- **Agents Host:** a second root, `/tmp/run-w105h`, opened with `AGENTS_ROOT` and `AGENTS_HOST_WEB_PORT=18866`, then set to **Run It Here**.
- Everything was done by AX press, by pid (Settings by its exact title), with no clicks or keys.
- Every shot was captured by window id.
- After #111 there is no grant to choose, so the sheets were checked for anything still saying grant, device or operator.

## Checked and left as they are

- **The code is readable and copyable in both sheets.** It is selectable monospaced text with a **Copy** button. It wraps at the hyphen in `agents-control`. That was left alone, because a non-breaking hyphen would change what a selection copies.
- **No grant, device or operator words in either sheet.** The code's fourth field still reads `operator`, which is #111's choice for older readers.
- **The 071 spec and wireframe E still describe the "It may" Device/Operator picker** (US1, FR-012, FR-013, FR-016). They are left as the record of what was decided then; #111 retired it.
- **When the window's control plane serves no page at all** (`status.web` is nil, Agents Host's switch off), the window's sheet says "Turn on Serve Agents to browsers on this Mac in Agents Host first." That case wasn't shot: run-app always serves the page.
