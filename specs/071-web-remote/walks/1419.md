# Walk: zoom the text of a Markdown page (#1419)

**Date:** 2026-10-18

**How it was run:**
- A run-app scratch root, `/tmp/run-zoom1419`, with its host and its control plane. A project `work` with `notes.md`, pinned with `pins/pin`.
- The Mac: the scratch window (`AgentsStore`, Debug), on a locked screen, driven by `walk.py`.
- The Remote: the "Agents Walk" simulator (iPhone 17 Pro), paired with the scratch control plane, driven by `walk.py remote`.
- The web page: headless Chrome, 1440 × 900, paired with a fresh browser code.
- Shots are in `walks/1419/`.

| What | Seen |
|---|---|
| Mac, 100 % and 150 % (`mac-100.png`, `mac-150.png`) | Prose, headings, code (keywords and comments too) and the measure grow 1.5 times. The sidebar does not change. The level was set in the walk's defaults (`pageTextZoom`), and the page changed at once. |
| Mac, a passage opened at 150 % | The editor's text is the same size as the page's. Nothing jumps. |
| Mac, View ▸ Zoom In / Zoom Out / Actual Size and a pinch | **Not walked.** The screen was locked, and a window opened behind is not key, so its menu items were off (Show Sidebar too). |
| Remote, 100 % and 150 % (`remote-100.png`, `remote-150.png`) | The same. A long code line scrolls sideways, as before. |
| Remote, the app quit and opened again at 150 % | The page opened at 150 %. |
| Remote, ⌘+ and a pinch | **Not walked.** The walk socket has no hardware keyboard and no gestures. |
| Web, ⌘= three times (`web-100.png`, `web-150.png`) | 100 % → 150 %: the paragraph's height 33.8 → 50.7 px; the sidebar stays 300 px; `localStorage.pageTextZoom` is `1.5`, and it is still `1.5` after a reload. |
