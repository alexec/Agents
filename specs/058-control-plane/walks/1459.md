## Set-up

- **Control plane:** `compose.public.yaml` + `compose.pebble.yaml`, so
  `AGENTS_CONTROL_PUBLIC_WEB=/web` (the image's own `Web/dist`) at
  `https://agents.127.0.0.1.sslip.io:8444`. Caddy had a certificate from Pebble at once.
- **Pin, for this walk only:** the Go `agentsd` on a Mac has no test-root hook (the Swift one
  had `AGENTS_TEST_TRUST_ROOT`), so the Mac host and the window trusted Caddy's certificate by
  its pin: a compose file of the walk's own set `AGENTS_CONTROL_PIN` to the SHA-256 of Caddy's
  key, and the codes carried it. Production codes carry none.
- **Mac host:** the Debug `agentsd` from `build/DD`, root `/tmp/run-p1459`,
  `AGENTS_MACHINE_ID=p1459-walk-mac`, joined with a host code from
  `docker exec … /agents-control code --host`.
- **Scratch window:** the `AgentsStore` Debug build, copied to `/tmp/run-p1459/app` with the
  bundle id `com.alexecollins.agents.walk`, an ATS exception for `sslip.io`, and **no app
  group** (the group holds #1118's local socket; without it the copy reaches the host only
  through the Pebble control plane and shares nothing with Alex's apps). Signed ad hoc, opened
  with `AGENTS_CONTROL=<client code>` and `--walk run-p1459`, driven with `walk.py` (its
  container path changed in a copy under `/tmp`). The screen was locked throughout.
- **Browser:** headless Chrome with a throwaway profile (`Web/test/walk/cdp.mjs`, which now takes
  extra flags), trusting Caddy's key by `--ignore-certificate-errors-spki-list`.
