# Walk: the live control plane on Google Cloud, and back (#1461)

2026-10-18 local (Pacific), 2026-10-18 and 2026-10-19 UTC. The v0.5 lead did the deploy and the
move. Alex clicked the sheets in Agents Host. This walk used Alex's live control plane, Mac
host, relay, window, iPhone and iPad. The walk with scratch clients only, before it, is
[1461-scratch.md](1461-scratch.md).

## Set-up

- **Google Cloud:** the project `agents-control`, with Alex's billing account linked to it.
  The scripts act as a service account with a key in `~/.agents/secrets/gcp-agents-control.json`.
- **The machine:** made by `deploy/gcp/up.sh`. The e2-micro VM `agents-control` in
  `us-west1-b`, Debian, with a 30 GB `pd-standard` disk and the static IPv4 address
  34.169.154.90. It runs as the service account `agents-control-vm`, which may only encrypt
  and decrypt with the Cloud KMS key `agents/control` (global). It has no service account key
  file.
- **The names:** made by `deploy/cloudflare/dns.sh` in the `agentloops.dev` zone, which Alex
  bought at Cloudflare (#1468). The A records `control.agentloops.dev` and
  `views.agentloops.dev`, DNS only.
- **Certificates:** Let's Encrypt, from Caddy, for both names, to 2027-01-16.
- **The control key:** sealed in the store by Cloud KMS (#1458).
- **The APNs key:** Alex's `.p8` key, given with `up.sh --apns`, as a compose secret.
