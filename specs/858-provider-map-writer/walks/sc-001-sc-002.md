## Found and fixed on the way

The first try, before the fix, failed. The agent's first check used `name` and `state`, which
read no item, so `check_draft` answered only "Passed: listed 0." The agent could not see the
answer, so it decided that the account had no machines. It sent a map with fields it had
guessed. A probe check with a wrong `items` then answered only "finds no list".

Now `check_draft` tells the agent what a map missed:

- When items were found and the map reads fewer of them, it adds "N of the M items at
  list.items have no id or name by this map. The first item:" and the first item as JSON.
  The JSON is redacted and cut at 2 KB.
- When `list.items` finds no list, the error names the answer's keys ("Its answer has the keys
  machines."). The sheet sees this too.

Tests: `checkShowsAnItemTheMapMissed` and `checkAgainstTheWalkServer` (this server, through
`ProviderConnection`).
