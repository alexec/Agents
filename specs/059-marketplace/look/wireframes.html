B · Add a skill: search
One sheet, opened from Settings ▸ Shared (aimed at you) or from a project page (aimed at that project, frame D). Add to says where it will go and can be switched here. Results come from skills.sh as you type, most-installed first. The owner is shown on every row, because it is the only thing that says who wrote it. Known marks an owner on the app's short list (Anthropic, OpenAI, Google, GitHub, Vercel, Apple…); everything else is plain, not flagged: most good skills come from people.

C · Add a skill: what is in it, before it goes in
Nothing is added from the list. Choosing a row fetches that skill at the repo's current commit and shows it as the agent will read it: SKILL.md, every file beside it, and which runtimes will get it (054's dots, for the place Add to points at). A skill that brings scripts says so, because an agent may run them. Add copies exactly what is shown, at that commit, and nothing later.
