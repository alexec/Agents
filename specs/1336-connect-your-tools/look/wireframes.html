B · Connect GitHub: one OAuth 2 sheet, the same for every tool
Every tool that needs an account connects with this sheet: its name, what Agents will be able to do in plain words, and Continue on ‹site›. The browser does the approving; the sheet waits and closes by itself when the site says yes. No CLI to install, no token to paste. The host’s Go client then calls the tool’s API directly with that token.
