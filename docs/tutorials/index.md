# Tutorials

Lessons. Each one takes you from nothing to something working, one step at a time, and
every step says what you should see. Start with the first; they are in order.

1. [Your first agent](first-agent.md): build Agents, add a project, and have an agent
   fix a failing test. About fifteen minutes.
2. [Follow your agents from your iPhone](follow-from-iphone.md): put Agents on your phone,
   answer an agent from it, and start another. About ten minutes.
