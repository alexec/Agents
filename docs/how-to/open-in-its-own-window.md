# Open a session or a folder in its own window

Sometimes you want two things on screen at once: a chat beside the one you are in, or one
folder on a second display while the main window shows all of them. A session or a
folder can open in a window of its own. The main window does not change, so you do not
lose your place in it.

## Before you start

- A session or a folder to open. See the [tutorials](../tutorials/index.md).

## A session in its own window

**Mac**

1. Select the session in the sidebar.
2. Choose **Session ▸ Open in New Window** (Shift-Option-Command-O). Or right-click the
   session's row and choose **Open in New Window**.

The window has only the chat: the conversation, the prompt, the question cards and the
plan. Its toolbar has **Pin**, **Rename** and **Archive**. It has no sidebar and no
inspector panes; to use those, go back to the main window.

The **Session** menu acts on the session in the front window. So **Stop** (Command-.) in a
session's own window stops that session, not the one selected in the main window. When the
window is in front, its session counts as read.

**iPad**

1. Touch and hold the session's row in the sidebar or its card on the folder's page, and
   choose **Open in New Window**. Or, in the conversation, open the **Actions** menu and
   choose **Open in New Window**.
2. Or drag the session's row out of the sidebar.

The session opens in a scene of its own, which you can put beside the main one with Split
View or Stage Manager.

**iPhone**

An iPhone shows one window at a time, so it has no **Open in New Window**.

**Web page**

Open the session row's menu and choose **Open in New Tab**. The tab has that session's own
address, so you can also keep it as a bookmark.

**What each window keeps**

- There is one window for each session. Opening it again brings that window to the front.
- If the session is archived, the window stays open and says so, with **Unarchive**.
- If the session is deleted, the window says **This session was deleted**. Close it.
- A question answered in one window goes from the other, because both show the same
  session.

## A folder in its own window

**Mac**

Do one of these:

- Double-click the folder's heading in the sidebar.
- Right-click the heading and choose **Open in New Window**.
- Select the folder and choose **Window ▸ Open Folder in New Window** (Option-Command-O).
- Choose **Window ▸ Open Folder Window**, then the folder.
- Right-click the Agents icon in the Dock and choose the folder.

The window has a sidebar of only that folder: **New Session**, its **Pinned** and
**Needs You**, its sessions, its workflows, **Archived**, and **Folder Settings…** at the
foot. A session you start or select there opens in that window. The window has its own
inspector, and it keeps the pane and the width for that folder. Its toolbar also has the
folder's shell (Control-`).

When a session in another folder needs you, the toolbar shows **✋ N elsewhere**. Click it
to go to the first of them.

To bring the main window back, choose **Window ▸ Agents (All Folders)** (Command-0).
If you close the main window, the folder windows stay open. A folder window opens again
when Agents starts. A notification for a session in that folder opens in its window.

**iPad**

Touch and hold the folder's heading in the sidebar and choose **Open in New Window**. The
folder opens in a scene of its own, with the same sidebar of only that folder.

**iPhone**

Touch and hold the folder's heading and choose **Open Folder Alone**. The screen shows
only that folder. Tap **‹ All** to go back to every folder. **✋ N elsewhere** shows when
a session in another folder needs you.

**Web page**

Open the folder heading's menu and choose **Open in New Tab**. The tab holds that folder
alone and has its name as its title. Click **‹ All** to see every folder again.
**✋ N elsewhere** shows when a session in another folder needs you.

On the iPad, the iPhone and the web page, a folder's workflows and archived sessions open
from the sidebar of every folder. Only the Mac's folder window shows them in place.
