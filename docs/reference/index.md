# Reference

Complete lists of what the app has, each entry described the same way. For looking
something up, not for reading through.

- [Statuses and groups](statuses.md): every status an agent can show, the group it sits
  under, and what you can do from there.
- [Runtimes](runtimes.md): the eight coding agents the app can start, and what each can do
  in the app.
- [Tools the app gives agents](agent-tools.md): every tool an agent gets from the app, and
  whether you are asked before it runs.
- [Settings, and the Runtimes and Resources pages](settings.md): every control in Settings
  on the Mac, the Runtimes and Resources pages, and what iPhone and iPad need.
- [The `~/.agents` folder](agents-folder.md): every file in it, what writes it, and what
  stays on each machine.
- [Workflow triggers and actions](workflows.md): the workflow file format, every trigger
  and setting, and when a workflow does not run.
- [Workspace providers](workspace-providers.md): the tools a workspace provider offers, and
  how the control plane checks and calls them.
- [Integrations](integrations.md): every third-party service and tool the app talks to,
  starts, installs or signs in to, with its state and when it was last checked.
- [ssh options](ssh-options.md): how each option in your `~/.ssh/config` fares when the
  control plane connects to a server.
- [Personas](personas.md): the persona file format, where personas live, and what picking one does.
- [Events](events.md): everything the app records, for waits, workflow triggers and the
  Events page.
- [Groups](groups.md): groups of people, and the workspace providers each group may start
  machines from.
- [On Every Machine](on-every-machine.md): the settings and secrets the control plane keeps
  for you and sends to each machine of yours.
- [Reports](reports.md): usage, cost and time by person, project and machine, added up on
  the control plane.
- [Keyboard shortcuts](keyboard-shortcuts.md): every shortcut and menu command on the Mac.
- [Feature matrix of coding-agent apps](feature-matrix.md): which apps for running several
  coding agents have which features, Agents included.
