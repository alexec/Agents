## Should this review be a step of every release?

Decided: yes, as step 10 of the release skill, but small: the release writes the timeline
and the table of what a person did into `~/.agents/reviews/releases/v<version>.md`, and
files an issue (at most three) only for a manual step that has no issue yet. Because it
costs a few minutes, and the times are easy to get while the session is still open. The
file is outside the project because the release changes no file in it. Alex can overrule.
