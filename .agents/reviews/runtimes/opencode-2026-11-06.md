OpenCode has no sign-in on this Mac (`opencode auth list`: 0 credentials), so only its free models (`opencode/*-free` and `opencode/big-pickle`) were offered.

## Result: not assessed

No step ran. Each assessment stopped at its first model request, because OpenCode's free models refused it: "Free usage limit reached. Free models work in OpenCode; subscribe to OpenCode Go to keep going". The daemon scored the first run 0 of 16 when it was stopped. That score is about the provider, not the integration, so it is not the result.

## What the free allowance is

- At the same minutes, `opencode run` turns on `big-pickle`, `glm-5.3-flash-free` and `mimo-v2.6-flash-free` passed, also with the assessment's brief as context and with the daemon's `OPENCODE_CONFIG_CONTENT` (the brief as an instructions file, #2612). The instructions file is not the cause.
- The daemon's own ACP requests, played again by hand, were refused with the app's MCP server (`agents`, 58 tools, 82 KB of tool schemas, about 20,000 tokens more a request) and passed without it (13,400 input tokens).
- Halving the tool list then gave answers that did not repeat. After about 25 more turns, every turn was refused, also with no tools. So the limit is an allowance spent over time, not a rule about a tool. Sessions with the app's tools spend it faster, because each request is about 2.5 times as large.

So an assessment (six turns, about 20 model requests, each with the app's tools) cannot run on OpenCode's free models. It needs an account: an OpenCode Go subscription, or a provider key OpenCode can use (an Anthropic, OpenAI or xAI API key; OpenCode borrows the Mac's provider keys). This Mac has neither. #1359 has `needs-account`.

## What to fix

- **A refused turn stays running forever (#3736).** After the provider's error, OpenCode sends no `session/update` with it and never answers `session/prompt` (also over ACP by hand, with no app in between). The person sees a session that works for ever. `assess.py`'s fallback to the default model waits for a turn end that never comes. Fix in the app: end such a turn with a line that says why; and report it to OpenCode.
