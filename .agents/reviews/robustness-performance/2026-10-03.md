## Summary

Sixteen issues were filed, **#163–#178**, all labelled `bug`:
- **Critical:** 1 (#163)
- **High:** 7 (#164–#170)
- **Medium:** 6 (#171–#176)
- **Low:** 2 (#177, #178)

The top three:

1. **A runtime that dies makes the daemon spin (#163).** The daemon never ends the session of a runtime that exits by itself. Its stderr handler then fires for ever at end of file. Measured: 10 runtimes killed mid-turn took agentsd to **~950 % CPU** and leaked **7 descriptors each**.
2. **Every agent change costs time in proportion to everything the host holds (#164, #165).** On the daemon, one label change costs **15 ms at 5,000 agents against 1.15 ms at 10**, which caps the host at about 66 changes a second. Opening a chat's record costs **130 ms against 0.7 ms**. The Mac window sits at **~128 % CPU** at 53 changes a second, with every project folded.
3. **Runtimes have no deadline (#166).** A silent adapter leaves an agent "working" for ever. One hung pick-up after a restart blocks every later one, and one hung availability check keeps its runtime out of the pool until a restart.

The live logs found three things the code reading did not:
- **Agents Host reconnects every 5 s (#168).** The daemon treats it as a stranger: 25,046 connections in 2.5 days, about 64 % of daemon.log.
- **A window dialled 9 times a second for 12 minutes (#172).**
- **A crash with no crash note (#178).**

## Checked and found sound

These areas showed nothing worth filing:
- **Agent records:** written atomically, serialised through `saveTail`, and validated before writing.
- **Transcripts:** appended on a kept handle; a torn line is ended (#88); the readers and turn caches are capped at 16.
- **Every whole-file store:** written with `.atomic` (temp + rename). Identical bytes are skipped for tiles, order, history and project.json.
- **Dashboard writers** (`setTile`, `moveTile`, `arrange`, `remove`): synchronous on the actor, with no `await` between read and write, so concurrent agents can't interleave.
- **project.json (#126):** unknown keys are kept, a hand-broken file is refused rather than overwritten, and the watcher only clears the cache.
- **workflows.json read-modify-write:** reloaded after each await. The fail-open case is #169.
- **Events:**
  - bounded at 7 days or 10,000;
  - appended per event;
  - served from memory;
  - trigger matching is per project with a chain-depth guard.
- **Leases:** one deadline timer, and a ticker only while something is held. A corrupt file is set aside.
- **Daemon socket:** SIGPIPE is ignored, the line is encoded once for every connection, and a 10 s write deadline closes a stuck client (measured above).
- **Host loss mid-call:** answered with `hostOffline` (#77). Both ends ping (#80).
- **Reconnect on wake and network change:** for the window and the uplink (#82).
- **Daemon start-up with 5,000 archived agents:** one index read plus a stat each, with no N+1 record reads.
- **Disk full (live, 2026-10-01):** writes failed cleanly and logged, and nothing was torn.
- **Memory bounds:** the window's events are capped at 1,000 and terminal output at 4 MB. Agent lists are lean (#107).
- **Timers:**
  - the slim sweep runs every 60 s and retention hourly;
  - the dashboard pages' 15 s timers run only while shown;
  - `TimelineView`s run only on screen.
