# reducer/

`streams.json`: notifications applied in order to an empty `AgentsModel` by `apply(_:_:)`
(`Client/AgentsModel.swift`), with `watching` set and a page laid down by `replaceTranscript`
where a step says. The digest is the agents in order, the permission and question cards, the
entries held (an entry heard before its page lands after it, once: `heardSincePage`) and the
page as drawn.
