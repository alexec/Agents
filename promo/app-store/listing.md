## Description (4000)

```text
Keep your editor and the coding agents you already use. Loops runs several of them at once, shows which one needs you, and lets you answer from wherever you are.

RUNS THE AGENTS YOU ALREADY HAVE
Claude, Codex, Gemini, Antigravity, Grok, Copilot, Cursor and OpenCode, each signed in with your own account and plan. Loops brings no model and no bill of its own. You choose the runtime, the model and the permission mode for each agent.

SEE WHICH AGENT NEEDS YOU
Every agent is in one group: Needs you, Waiting, Working, Done or Paused. When an agent ends its turn, it says in one sentence how it went. Read the list and you know what to open.

SEE THE WORK, NOT ONLY THE CHAT
A plan or a review that an agent writes opens beside the conversation and fills in as the agent writes. You can type on it while it grows. Diagrams show as pictures. Code changes are coloured down to the word.

AGENTS THAT WORK TOGETHER
Agents take turns with a simulator, a browser or the screen, so two of them never use it at once. An agent can wait for another agent, a branch or a pull request, and costs nothing while it waits. A workflow, a Markdown file in your repository, starts an agent on a schedule or when something happens. An agent can start helpers, each in a worktree of its own.

THEY KEEP GOING WITHOUT YOU
Your agents run in Agents Host, a helper on your Mac, not in this app. Close the app and they carry on. After the Mac restarts, the agents that were working pick up where they stopped.

ANSWER FROM ANYWHERE
On the iPhone and iPad you see the same list. Read a conversation as it happens, answer a question, send a prompt or a photo, and start and stop agents. When an agent needs you and you are away from the Mac, the device you used last gets a notification.

YOUR MACHINES
The work runs on your Mac, or on a Linux server of your own. Every agent's spending, on every runtime and server, adds up to one figure for the day, and you can set a limit.

WHAT YOU NEED
- A Mac with Agents Host, a free download. It runs your agents, and this app is the window onto them. The app shows you where to get it, and docs.agentloops.dev says how to set it up.
- An account with at least one of the coding agents above.

Loops' source is visible at github.com/alexec/Agents (all rights reserved).
```
